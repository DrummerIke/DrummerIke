# G7 start page

Стартовая страница для добавления сайта G7 на экран «Домой».

## Файлы

Все файлы должны лежать рядом в одной папке на хостинге:

```text
g7/
├── index.html
├── manifest.webmanifest
├── favicon.svg
├── icon-180.png
├── icon-192.png
├── icon-512.png
└── README.md
```

`index.html` использует относительные пути `./favicon.svg`, `./icon-180.png`, `./icon-192.png` и `./manifest.webmanifest`, поэтому не переименовывайте файлы и не переносите изображения в отдельные папки без изменения HTML.

## Важно про PNG-иконки

PNG-файлы `icon-180.png`, `icon-192.png` и `icon-512.png` не хранятся в этом репозитории как бинарные файлы. Перед загрузкой на хостинг их нужно создать или вставить вручную рядом с `index.html`. Готовый prompt для GPT/исполнителя находится в [`GPT_ASSET_PROMPT.md`](./GPT_ASSET_PROMPT.md).

## Как работает

Обычное открытие страницы показывает экран с кнопкой перехода на сайт G7. Если страница запущена с домашнего экрана в standalone-режиме, она автоматически перенаправляет пользователя на:

```text
https://sites.google.com/view/borkg7/
```
